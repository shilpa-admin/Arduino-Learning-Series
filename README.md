 # Arduino Learning Series

**By Aariv Technologies**

Welcome to the Arduino Learning Series! This repository contains the source code and circuit diagrams used in our Arduino tutorials.

The series is designed for beginners, students, and electronics enthusiasts who want to learn Arduino programming through simple, practical, hands-on experiments.

Our objective is to help learners understand basic electronics, microcontrollers, programming concepts, and hardware interfacing through real-world projects.

## Learning Objectives

Through this series, you will learn:

- Introduction to Arduino and microcontrollers
- Arduino UNO board architecture and pin configuration
- Installing and working with Arduino IDE
- Basic Arduino programming
- Digital input and output operations
- Interfacing LEDs and pushbuttons
- Pulse Width Modulation (PWM)
- Analog input using potentiometers
- Serial communication and Serial Monitor
- Interfacing passive buzzers and generating tones

## Hardware Requirements

The experiments primarily use:

- Arduino UNO
- USB cable
- Breadboard
- LEDs
- Resistors (220 Ω, 330 Ω and 10 kΩ)
- Pushbuttons
- Potentiometer (10 kΩ)
- Passive buzzer
- Jumper wires

Additional components may be required for specific experiments.

## Software Requirements

- Arduino IDE 2.x
- Arduino UNO board support package
- USB drivers, if required by compatible third-party boards

## Getting Started

1. Download or clone this repository.
2. Open the required `.ino` file from the `Arduino-Codes` folder using Arduino IDE.
3. Connect your Arduino UNO to your computer.
4. Select the appropriate board and port.
5. Verify and upload the program.
6. Follow the corresponding circuit diagram to complete the experiment.

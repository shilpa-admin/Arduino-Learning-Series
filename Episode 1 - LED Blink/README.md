# Episode 1 – LED Blink

**Arduino Learning Series | Aariv Technologies**

Learn how to blink the built-in LED on the Arduino UNO using a simple Arduino program.

## Circuit Diagram

The Arduino UNO has an onboard LED connected to digital pin 13 through a resistor.

No external wiring is required.

## Arduino Program

Refer to `LED_Blink.ino`.

## Working Principle

The built-in LED turns ON for one second and OFF for one second. This process repeats continuously using the `loop()` function.

## Learning Concepts

- Digital output
- `pinMode()`
- `digitalWrite()`
- `delay()`
- `setup()` and `loop()`
